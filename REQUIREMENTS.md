# Spring AI vs Langchain4J on Spring Boot and Quarkus

This file contains the requirements of the current project.

This is a didactical side project aiming at comparing Spring AI and Langchain4J.
Here is the general workflow of the project development: a Spring AI example 
implementing a specific case is provided by me. For each such file do:
  1. Convert it from gradle build to maven build.
  2. Provide two other implementations using Langchain4J, one for Spring Boot and another one for Quarkus.
  3. If Jakarta Agentic is stable enough and makes sense, provide a separate implementation as well.

Please use the agents, skills and all the required material in the ~/.claude 
directory in order to create these implementations, such that they demonstrate
a high quality level.

Also, the name of the project isn't perhaps relevant. Should it be the case, 
please don't hesitate to propose more appropriated names.
